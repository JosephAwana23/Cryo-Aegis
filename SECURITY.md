<a name="english"></a>
## English

### Reporting a Vulnerability
The **Cryo-Aegis** project takes the security of operational technology (OT), clinical blood bank systems, and retail cold-chain infrastructure seriously. If you discover a security vulnerability or bypass within this repository, please report it responsibly rather than disclosing it publicly.

* **Email:** Report security findings directly to the project author (Joseph Awana / JosephAwana23) or open an encrypted advisory draft on GitHub.
* **Scope:** Vulnerabilities in the honeypot (cryo_aegis_gui.py), Modbus polling registers (cryo_modbus.py), Censys/Discord connectors (cryo_censys_discord.py), or associated OT protocols.

### Supported Versions
| Version | Supported |
| :--- | :--- |
| v6.x (Current Master SOC) | ✅ Yes |
| v5.x and earlier | ❌ No |

## Français

### Signalement d'une Vulnérabilité
Le projet **Cryo-Aegis** prend très au sérieux la sécurité des technologies opérationnelles (OT), des systèmes de banques de sang cliniques et des infrastructures de chaîne du froid. Si vous découvrez une vulnérabilité de sécurité ou un contournement dans ce dépôt, veuillez le signaler de manière responsable.

* **E-mail :** Signalez vos découvertes de sécurité directement à l'auteur du projet (Joseph Awana / JosephAwana23) ou ouvrez un brouillon d'avis chiffré sur GitHub.
* **Périmètre :** Vulnérabilités dans le honeypot (cryo_aegis_gui.py), les registres de scrutation Modbus (cryo_modbus.py), les connecteurs Censys/Discord (cryo_censys_discord.py), ou les protocoles OT associés.

### Versions Supportées
| Version | Supportée |
| :--- | :--- |
| v6.x (Master SOC Actuel) | ✅ Oui |
| v5.x et antérieures | ❌ Non |
